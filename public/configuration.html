Dates are obtained from the first line that contains the text "1,2,3". The first comma separated value in that line must contain month and year like so: Sep-2026, Sep-26, 2026-09, 2026-Sep. The separator can also be space, comma, or slash

Occupancy data is obtained from lines that contain text "Room" (case insensitive). Values like XX, XY, X, -, (called 'cbr_id's here) are mapped to occupancy states according to the occupancy states table.

The legend is extracted from the first line enclosed by double quotes which contains the text "Legend".
